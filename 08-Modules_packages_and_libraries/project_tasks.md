# Проектные задания модуля 8

## Проект 3. Анализатор погодных данных — разделение на модули

Папка проекта: [`Projects/03-Weather_analyzer`](../Projects/03-Weather_analyzer/).

### Базовый уровень

Разделите содержимое `weather_analyzer.py`:

- классы перенесите в `models.py`;
- вычисления перенесите в `statistics.py`;
- запуск программы перенесите в `main.py`.

Настройте импорты и проверьте запуск `main.py`.

### Продвинутый уровень

Создайте файл `__init__.py` и экспортируйте из пакета основные классы и функции.

### Результат этапа

Анализатор состоит из нескольких модулей с понятными обязанностями.
