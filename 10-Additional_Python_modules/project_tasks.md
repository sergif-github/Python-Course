# Проектные задания модуля 10

## Проект 3. Анализатор погодных данных — даты, API и графики

Папка проекта: [`Projects/03-Weather_analyzer`](../Projects/03-Weather_analyzer/).

### Базовый уровень

1. Преобразуйте строки дат в объекты `datetime`.
2. Отсортируйте наблюдения по дате.
3. Постройте график температуры по дням.
4. Сохраните график в файл изображения.

### Продвинутый уровень

Создайте `api.py`, получите погодные данные через HTTP API и преобразуйте ответ в объекты `WeatherRecord`.

## Проект 4. Планировщик путешествий — первая версия

Рабочий файл: [`Projects/04-Travel_planner/travel_planner.py`](../Projects/04-Travel_planner/travel_planner.py).

### Базовый уровень

Реализуйте расчёт продолжительности поездки, дневного бюджета и последовательности городов маршрута.

### Продвинутый уровень

Подключите погодный анализатор и сформируйте прогноз для каждого города на даты поездки.

### Результат этапа

Погодный анализатор строит временной график, а планировщик рассчитывает основные параметры поездки.
