# Проектные задания модуля 6

## Проект 3. Анализатор погодных данных — модель данных

Рабочий файл: [`Projects/03-Weather_analyzer/weather_analyzer.py`](../Projects/03-Weather_analyzer/weather_analyzer.py).

### Базовый уровень

1. Реализуйте класс `WeatherRecord` с датой, городом, температурой, влажностью и скоростью ветра.
2. Реализуйте класс `WeatherDataset`, который хранит список наблюдений.
3. Добавьте метод вычисления средней температуры.

### Продвинутый уровень

Добавьте методы поиска минимальной и максимальной температуры и фильтрации наблюдений по городу.

### Результат этапа

Погодные данные представлены объектами, а набор наблюдений умеет рассчитывать основные показатели.
