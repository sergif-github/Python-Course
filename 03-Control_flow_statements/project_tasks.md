# Проектные задания модуля 3

## Проект 1. Калькулятор — выбор операции

Рабочий файл: [`Projects/01-Calculator/calculator.py`](../Projects/01-Calculator/calculator.py).

### Базовый уровень

1. Используйте `if`, `elif` и `else` для выполнения выбранной операции.
2. Выводите только результат выбранной операции.
3. Обработайте неизвестный пункт меню.
4. Перед делением проверьте, что второе число отлично от нуля.

### Продвинутый уровень

Добавьте проверку диапазона пунктов меню и отдельные сообщения для неверной операции и деления на ноль.

### Результат этапа

Калькулятор выполняет выбранную операцию и сообщает пользователю о недопустимом выборе.
