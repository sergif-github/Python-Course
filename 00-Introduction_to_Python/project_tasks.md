# Проектные задания модуля 0

## Проект 1. Калькулятор — запуск программы

Рабочий файл: [`Projects/01-Calculator/calculator.py`](../Projects/01-Calculator/calculator.py).

### Базовый уровень

1. Выведите заголовок `Простой калькулятор`.
2. Запросите у пользователя два числа.
3. Выведите оба полученных значения.
4. Запустите файл из терминала командой `python3 Projects/01-Calculator/calculator.py`.

### Продвинутый уровень

Добавьте понятные приглашения для ввода и итоговое сообщение, в котором оба числа выводятся в одной строке.

### Результат этапа

Программа запускается из терминала, получает данные пользователя и выводит их без ошибок.
