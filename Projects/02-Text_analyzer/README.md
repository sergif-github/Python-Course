# Проект 2. Текстовый анализатор

Проект объединит работу со строками, коллекциями, условиями, циклами и функциями. Студенты реализуют нормализацию текста, частотный словарь, основные статистики и отчёт о результатах анализа.

## Организация папки текстового анализатора

В начале проекта структура минимальна:

```text
Projects/
└── 02-Text_analyzer/
    ├── README.md
    └── text_analyzer.py
```

После изучения функций:

```text
Projects/
└── 02-Text_analyzer/
    ├── README.md
    ├── main.py
    ├── text_analyzer.py
    └── tests/
        └── test_text_analyzer.py
```

Финальная версия:

```text
Projects/
└── 02-Text_analyzer/
    ├── README.md
    ├── main.py
    ├── analyzer.py
    ├── normalization.py
    ├── reports.py
    ├── data/
    │   └── sample_text.txt
    └── tests/
        ├── test_analyzer.py
        └── test_normalization.py
```

Структура усложняется вместе со знаниями студентов. Папки и модули появляются тогда, когда они изучены.
