# Учебные проекты

В этой папке хранится рабочий код проектов курса. Задания по отдельным темам находятся в соответствующих учебных модулях, а файлы проектов постепенно дополняются студентами.

## Порядок проектов

1. [Калькулятор](./01-Calculator/)
2. [Текстовый анализатор](./02-Text_analyzer/)
3. [Анализатор погодных данных](./03-Weather_analyzer/)
4. [Планировщик путешествий](./04-Travel_planner/)

Первый проект — калькулятор. Он выполняется после изучения пользовательского ввода, операторов, условий, циклов и функций. Следующие проекты постепенно подключают работу с текстом, объектно-ориентированное программирование, файлы, API, визуализацию и тестирование.
