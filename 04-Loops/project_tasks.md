# Проектные задания модуля 4

## Проект 1. Калькулятор — повторные вычисления

Рабочий файл: [`Projects/01-Calculator/calculator.py`](../Projects/01-Calculator/calculator.py).

### Базовый уровень

1. Поместите меню и вычисления в цикл `while`.
2. Добавьте пункт `Выход`.
3. Завершайте цикл с помощью `break` после выбора пункта выхода.
4. После вычисления снова показывайте меню.

### Продвинутый уровень

Добавьте историю результатов в список и выводите её перед завершением программы.

### Результат этапа

Пользователь может выполнить несколько вычислений за один запуск программы и завершить её через меню.
