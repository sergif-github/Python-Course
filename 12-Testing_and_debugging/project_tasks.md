# Проектные задания модуля 12

## Проект 4. Планировщик путешествий — тестирование итоговой версии

Папка проекта: [`Projects/04-Travel_planner`](../Projects/04-Travel_planner/).

### Базовый уровень

Напишите тесты для:

- продолжительности поездки;
- дневного бюджета;
- пустого маршрута;
- неверного диапазона дат;
- сохранения и загрузки поездки.

### Продвинутый уровень

Подмените ответ погодного API подготовленными данными и проверьте интеграцию планировщика с погодным анализатором.

## Итоговая проверка предыдущих проектов

Добавьте отдельные тесты для арифметических функций калькулятора, нормализации текста и статистики погодных наблюдений.

### Результат этапа

Каждый проект имеет воспроизводимые автоматические проверки, а итоговый планировщик корректно обрабатывает обычные и граничные случаи.
