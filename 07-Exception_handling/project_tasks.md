# Проектные задания модуля 7

## Проект 3. Анализатор погодных данных — проверка данных

Рабочий файл: [`Projects/03-Weather_analyzer/weather_analyzer.py`](../Projects/03-Weather_analyzer/weather_analyzer.py).

### Базовый уровень

1. Проверяйте, что влажность находится в диапазоне от 0 до 100.
2. Проверяйте, что название города заполнено.
3. При неверных данных возбуждайте `ValueError` с понятным сообщением.
4. Обработайте ошибки при создании наблюдения из пользовательского ввода.

### Продвинутый уровень

Создайте собственное исключение `InvalidWeatherDataError` и используйте его для ошибок погодного наблюдения.

### Результат этапа

Проект отклоняет некорректные данные и сообщает причину ошибки.
