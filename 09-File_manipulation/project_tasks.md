# Проектные задания модуля 9

## Проект 3. Анализатор погодных данных — CSV и JSON

Папка проекта: [`Projects/03-Weather_analyzer`](../Projects/03-Weather_analyzer/).

### Базовый уровень

1. Создайте `loaders.py`.
2. Реализуйте загрузку погодных наблюдений из CSV.
3. Сохраните рассчитанный отчёт в JSON.
4. Пропускайте повреждённые строки с сообщением об ошибке.

### Продвинутый уровень

Поддержите загрузку и CSV, и JSON через одну функцию `load_weather_data(filename)`.

## Расширение проекта 2. Текстовый анализатор

Добавьте чтение исходного текста из файла и сохранение отчёта в JSON. Это расширение можно выполнить после завершения базового задания погодного проекта.

### Результат этапа

Проекты загружают реальные данные из файлов и сохраняют результаты обработки.
