# Проектные задания модуля 2

## Проект 1. Калькулятор — вычисления

Рабочий файл: [`Projects/01-Calculator/calculator.py`](../Projects/01-Calculator/calculator.py).

### Базовый уровень

Вычислите для двух введённых чисел:

- сумму;
- разность;
- произведение;
- частное.

Выведите результаты с названиями операций.

### Продвинутый уровень

Добавьте возведение в степень, целочисленное деление и остаток от деления.

### Результат этапа

Программа правильно выполняет арифметические операции для нескольких наборов входных данных.
