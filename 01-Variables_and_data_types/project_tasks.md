# Проектные задания модуля 1

## Проект 1. Калькулятор — данные и меню

Рабочий файл: [`Projects/01-Calculator/calculator.py`](../Projects/01-Calculator/calculator.py).

### Базовый уровень

1. Преобразуйте введённые значения в `float`.
2. Сохраните названия операций в списке.
3. Выведите пронумерованное меню сложения, вычитания, умножения и деления.
4. Сохраните выбор пользователя в отдельной переменной.

### Продвинутый уровень

Создайте словарь, связывающий номер пункта меню с названием операции и её знаком.

### Результат этапа

Программа хранит числа в подходящем типе данных и показывает пользователю меню операций.
