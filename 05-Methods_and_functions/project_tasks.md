# Проектные задания модуля 5

## Проект 1. Калькулятор — итоговая версия

Рабочие файлы:

- [`Projects/01-Calculator/calculator.py`](../Projects/01-Calculator/calculator.py);
- [`Projects/01-Calculator/check_calculator.py`](../Projects/01-Calculator/check_calculator.py).

### Базовый уровень

1. Реализуйте функции `add`, `subtract`, `multiply`, `divide` и `exponentiate`.
2. Перенесите интерактивное меню в функцию `calculator`.
3. Запустите открытые проверки командой `python3 Projects/01-Calculator/check_calculator.py`.

### Продвинутый уровень

Создайте функцию `calculate(operation, first_number, second_number)`, которая выбирает нужное вычисление и возвращает результат.

## Проект 2. Текстовый анализатор — первая версия

Рабочий файл: [`Projects/02-Text_analyzer/text_analyzer.py`](../Projects/02-Text_analyzer/text_analyzer.py).

### Базовый уровень

Реализуйте функции для подсчёта символов, слов, уникальных слов и средней длины слова. Функция `analyze_text` должна возвращать результаты в словаре.

### Продвинутый уровень

Добавьте нормализацию регистра, удаление простых знаков препинания и список пяти наиболее частых слов.

### Результат этапа

Калькулятор завершён, а текстовый анализатор принимает строку и возвращает основные статистики.
